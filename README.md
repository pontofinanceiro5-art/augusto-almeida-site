# Augusto & Almeida - Sociedade de Advogados

Website institucional corporativo e tributário para a sociedade de advogados Augusto & Almeida.

## 🚀 Tecnologias

- **React 18** + **Vite 6**
- **TailwindCSS 4**
- **Lenis Smooth Scroll**
- **GSAP + ScrollTrigger**
- **Lucide Icons**
- **CI/CD**: GitHub Actions & Netlify

## 🛠️ Como rodar localmente

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev

# Compilar para produção
npm run build
```

## 📦 Deploy Status

- **GitHub Pages**: Configurado via GitHub Actions (`.github/workflows/deploy.yml`)
- **Netlify**: Configurado via `netlify.toml`
